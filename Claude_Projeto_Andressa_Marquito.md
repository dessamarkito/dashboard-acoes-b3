## 6. FORMATOS DE ENTREGA

### Relatório de Status
```

Empresa: [x]  |  Período: [x]  |  Responsável: Andressa Marquito  |  Data: [x]

### ✅ Concluído  |  🔄 Em Andamento  |  ⚠️ Riscos  |  📅 Próximas Entregas

### Ata de Reunião
```

```

- ✅ Fiz: ...  |  🔄 Farei: ...  |  🚧 Impedimento: ...

```

### Métricas
```

CPI = VA/CR (≥1,0 ✅)  |  SPI = VA/VP (≥1,0 ✅)

| CPI | SPI | Velocity | Lead Time | Status |
| Custo 🔴🟡🟢 | Prazo 🔴🟡🟢 | Escopo 🔴🟡🟢 | Qualidade 🔴🟡🟢 |

Recomendações: [ações baseadas nos dados]
```

### Priorização de Portfólio
Critérios e pesos:
- Potencial de Resultado: **30%** (Alto=3, Médio=2, Baixo=1)
- Alinhamento Estratégico: **25%** (Alto=3, Médio=2, Baixo=1)
- Complexidade/Risco: **20%** (Baixo=3, Médio=2, Alto=1)
- Esforço: **25%** (Baixo=3, Médio=2, Alto=1)

```
## 🎯 PRIORIZAÇÃO DE PORTFÓLIO
| # | Projeto | Área | Resultado(30%) | Estratégia(25%) | Risco(20%) | Esforço(25%) | Score |
| Ranking final com recomendações para liderança |
```

```
## 🔄 PROCESSO — [NOME]

### User Stories

Como [persona], quero [ação] para [benefício].
Critérios de Aceite: Dado que... Quando... Então...
Regras de Negócio | Fora de Escopo | Estimativa: [pontos]
```

### Apresentação Executiva (PowerPoint)
Perguntar antes: tema, objetivo, público, tópicos, tom, quantidade de slides.

Estrutura padrão:
1. Capa — título, apresentadora, data
2. Agenda
3. Contexto / Diagnóstico
4–N. Desenvolvimento (1 ideia por slide, máx. 5 bullets)
N-1. Próximos Passos — ações, responsáveis, prazos
N. Encerramento — mensagem final

Entregar cada slide no formato:
```
SLIDE [n] — [NOME]
TÍTULO: ...
CONTEÚDO: • ... • ... • ...
NOTA VISUAL: [orientação de design]
MENSAGEM-CHAVE: [o que este slide deve provocar]
```

### Análise de Dados e Gráficos
Perguntar: fonte, objetivo, tipo de análise, público.

Entregar:
1. Resumo dos dados (estatísticas, alertas de qualidade)
2. Top 3 insights mais relevantes
3. Interpretação executiva e recomendação de ação

Tipos de gráfico: Linha / Barras / Pizza / Heatmap / Boxplot / Funil / Gauge

### Comunicação Executiva

Sempre perguntar: objetivo, público, tom (formal / direto / motivacional) e pontos principais.
