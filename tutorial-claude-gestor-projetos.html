Módulo 02

Como instalar Skills no Claude

Passo a passo completo para configurar suas Skills no Claude.ai. O processo leva menos de 10 minutos.

1

Acesse o Claude.ai e abra "Projects"

No menu lateral esquerdo, clique em Projects (ou "Projetos"). Se não aparecer, certifique-se de estar em uma conta Pro ou Team.

🔑

Skills funcionam dentro de Projetos no Claude. Cada projeto pode ter suas próprias instruções personalizadas — crie um projeto por área: "Gestão Ágil", "Relatórios Executivos", etc.

2

Crie um novo Projeto

Clique em "+ New Project", dê um nome descritivo (ex.: "Gestão de Projetos — [Nome do Projeto]") e confirme a criação.

3

Acesse as Instruções do Projeto

Dentro do projeto criado, clique no ícone de ⚙️ configurações ou no link "Add project instructions" (instruções do projeto).

4

Cole sua Skill de contexto do projeto

No campo de instruções, insira o template abaixo adaptado para seu projeto. Este é o "perfil" que o Claude vai memorizar:

# CONTEXTO DO PROJETO Projeto: [Nome do Projeto] Cliente/Área: [Cliente ou Área de Negócio] Metodologia: Scrum | Kanban | Híbrido | Cascata Fase Atual: Iniciação | Planejamento | Execução | Encerramento Time: [Nº de pessoas e papéis principais] # MEU PAPEL Sou o Gerente de Projetos responsável por [descrever responsabilidade]. Reporto para [cargo do stakeholder] e minha cadência de relatório é [semanal/quinzenal/mensal]. # FORMATO DE SAÍDA PADRÃO - Relatórios: use tabelas e bullet points - Status: sempre com RAG (🟢 Verde / 🟡 Amarelo / 🔴 Vermelho) - Atas: estrutura com Pauta → Discussão → Decisões → Ações - Língua: Português brasileiro, tom profissional mas direto # MÉTRICAS QUE ACOMPANHO [ex: Velocity, CPI, SPI, Lead Time, Taxa de Defeitos, NPS interno] # FERRAMENTAS USADAS [ex: Jira, Confluence, MS Project, Monday, Trello, Excel]
5

Adicione documentos de referência

Ainda no projeto, use o botão "Add content" para fazer upload de documentos-chave: cronograma base, matriz de riscos atual, backlog do produto, organograma. O Claude vai consultá-los automaticamente.

📁

Formatos aceitos: PDF, DOCX, XLSX, TXT, CSV. Recomendação: adicione o plano do projeto e o backlog atualizado. Mantenha os documentos sempre frescos!

6

Salve e teste sua configuração

Clique em Save e inicie uma nova conversa dentro do projeto. Teste com o prompt: "Resuma o contexto do nosso projeto e liste as 3 principais métricas que devo monitorar esta semana."

Módulo 03

Prompts prontos para o seu dia a dia

Clique em cada categoria para expandir os prompts. Copie, adapte e use imediatamente no seu projeto.

📊

Status Report Semanal

Para reuniões de acompanhamento e e-mails executivos
▼
Com base nos dados abaixo, gere um Status Report executivo no formato RAG (🟢🟡🔴) para a semana [X]: DADOS DA SEMANA: - Tarefas concluídas: [lista] - Tarefas em atraso: [lista] - Principais impedimentos: [lista] - Próximas entregas: [lista] O relatório deve conter: 1. Sumário executivo (3 linhas) 2. Status geral do projeto (RAG com justificativa) 3. Progresso por área/workstream 4. Riscos e impedimentos ativos 5. Próximos marcos críticos (2 semanas) 6. Ações requeridas dos stakeholders Formato: tabela + texto. Tom: profissional e direto.

💡 Cole seus dados brutos no lugar dos colchetes e envie. O Claude formata tudo automaticamente.

⚡

Análise de Sprint (Retrospectiva)

Para retrospectivas ágeis e melhoria contínua
▼
Analise os dados da Sprint [número] e gere um relatório de retrospectiva estruturado: DADOS DA SPRINT: - Velocity planejado: [X] pontos | Realizado: [Y] pontos - Stories concluídas: [lista] - Stories não concluídas: [lista] (motivo: [motivo]) - Bugs encontrados: [N] - Impedimentos registrados: [lista] - Feedback do time: [comentários coletados] Gere: 1. Análise do Velocity (desvio % e tendência das últimas 3 sprints) 2. What Went Well / What Didn't / Action Items 3. Top 3 causas raiz dos atrasos (use 5 Porquês se necessário) 4. Recomendações para a próxima sprint 5. Meta de velocity ajustada com base na tendência
⚠️

Atualização do Risk Register

Para revisões periódicas de riscos
▼
Com base nas situações abaixo, atualize nossa matriz de riscos e sugira novos riscos que possam não ter sido identificados: SITUAÇÃO ATUAL DO PROJETO: [Descreva o contexto, ex: "Estamos na fase de integração, com dependência de API do fornecedor X que ainda não foi entregue. O prazo final é em 45 dias."] RISCOS JÁ MAPEADOS: [Cole ou liste os riscos existentes] Por favor: 1. Atualize o status de cada risco (Probabilidade × Impacto: Alto/Médio/Baixo) 2. Sugira até 5 novos riscos relevantes ao contexto 3. Para cada risco crítico (P×I = Alto), proponha plano de mitigação e contingência 4. Ordene por criticidade e gere a tabela no formato: ID | Risco | Prob. | Impacto | Status | Dono | Mitigação
📝

Ata de Reunião Automática

Para qualquer tipo de reunião de projeto
▼
Transforme as notas brutas abaixo em uma ata formal de reunião: NOTAS BRUTAS: [Cole aqui suas anotações, transcrição ou pontos discutidos — não precisa estar organizado] PARTICIPANTES: [lista de nomes e cargos] DATA/HORA: [data] | LOCAL/PLATAFORMA: [local] Gere a ata com: 1. Cabeçalho formal (Projeto, Data, Participantes, Objetivo) 2. Pauta discutida 3. Resumo das discussões por tópico 4. Decisões tomadas (destacadas em negrito) 5. Ações / Action Items no formato: | # | Ação | Responsável | Prazo | Prioridade | 6. Próxima reunião / próximos passos 7. Espaço para assinaturas (se necessário) Tom: formal e objetivo. Máximo 2 páginas.
📈

Análise de EVM (Earned Value)

Para projetos com orçamento e cronograma formal
▼
Calcule e interprete os indicadores de Earned Value Management para o período atual: DADOS: - BAC (Budget at Completion): R$ [valor] - PV (Planned Value / BCWS): R$ [valor] - EV (Earned Value / BCWP): R$ [valor] - AC (Actual Cost / ACWP): R$ [valor] - Data de início: [data] | Prazo final: [data] - % Concluído real: [%] Calcule e apresente: 1. CV (Cost Variance) e interpretação 2. SV (Schedule Variance) e interpretação 3. CPI (Cost Performance Index) — estamos acima/abaixo do orçamento? 4. SPI (Schedule Performance Index) — estamos adiantados/atrasados? 5. EAC (Estimate at Completion) — previsão de custo final 6. ETC (Estimate to Complete) — quanto ainda precisamos gastar 7. VAC (Variance at Completion) — desvio previsto 8. Semáforo RAG de cada indicador 9. Narrativa executiva de 5 linhas explicando a saúde financeira do projeto
📣

Comunicação para Stakeholders

E-mails, comunicados e apresentações executivas
▼
Preciso comunicar uma situação delicada para meu stakeholder principal. Redija o e-mail/comunicado adequado: SITUAÇÃO: [Descreva o que precisa ser comunicado — atraso, mudança de escopo, issue crítico, conquista importante] DESTINATÁRIO: [Cargo e perfil — ex: "Diretor de TI, perfil técnico, foco em resultados"] OBJETIVO da comunicação: [Informar / Pedir aprovação / Escalar / Celebrar] TOM desejado: [Formal / Profissional direto / Colaborativo] Gere: 1. E-mail completo com assunto impactante 2. Versão resumida para WhatsApp/Slack (máx. 5 linhas) 3. 3 possíveis perguntas que o stakeholder fará + respostas preparadas Importante: seja transparente, apresente o problema E a solução proposta juntos.

Módulo 05

Métricas ágeis que o Claude analisa para você

Referência rápida: o que é cada métrica, como coletar os dados e qual prompt usar para análise automática.

Métrica O que mede Dado necessário Frequência
🏃 Velocity Pontos de história entregues por sprint Story points concluídos por sprint (últimas 6) Por sprint
🔥 Burndown Progresso de entrega vs. planejado Pontos restantes por dia da sprint Diário
⏱️ Lead Time Tempo total: pedido → entrega Data criação e data conclusão de cada item Por sprint
🔄 Cycle Time Tempo de desenvolvimento ativo Data início "Em progresso" e data conclusão Por sprint
📉 CPI Eficiência de custo (EVM) EV e AC do período Mensal
📅 SPI Eficiência de prazo (EVM) EV e PV do período Mensal
🐛 Defect Rate Qualidade das entregas Bugs abertos / stories entregues Por sprint
🌊 CFD Gargalos no fluxo Kanban Qtd. itens por coluna ao longo do tempo Semanal
🎯

Dica de ouro: Exporte seu board do Jira ou Monday como CSV, faça upload no projeto do Claude e peça: "Analise este CSV e calcule velocity, lead time e cycle time das últimas 4 sprints. Identifique tendências e recomende 3 ações de melhoria." — você terá uma análise completa em segundos.
